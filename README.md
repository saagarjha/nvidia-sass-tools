# Nvidia SASS Tools

> [!WARNING]
> This project parses an undocumented specification with AI-generated code. While some effort has been made to verify the results, it is inevitable that some bugs may have slipped through. Don't use this for anything important!

Nvidia's tools contain a poorly researched but extensive specification inside them for their SASS instruction set architecture. After extracting it using scripts such as [this one](https://github.com/0xD0GF00D/DocumentSASS.git) the code here can help you build your own tools on top.
